# MLS NEXT quick reference: match length and substitutions

> Quick reference compiled 2026-10-16 from the official document(s) in this folder. If this sheet and the full document ever disagree, the full document wins.

Sources: MLS NEXT Academy Division Technical Standards 2026-2027; MLS NEXT Homegrown Division Technical Standards 2025-26
(the 2026-27 Homegrown standards were not available when this was compiled; check for an update).

## Academy Division (AD), 2026-27
| Age | Match length | Substitutions |
|---|---|---|
| U13 | 3 x 25-minute PERIODS, two 5-minute intermissions | 2 substitution moments per PERIOD, unrestricted (re-entry allowed); intermissions do NOT count as a moment |
| U14 | 2 x 40-minute halves, 10-minute halftime | 3 substitution moments per half, unrestricted (re-entry allowed); halftime does NOT count as a moment |
| U15, U16, U17, U19 | 2 x 45-minute halves, 10-minute halftime | 3 substitution moments per half, NO re-entry in the half; halftime does NOT count as a moment |
Exceptions apply under the MLS NEXT Concussion Protocol.

## Homegrown Division (HD), 2025-26
| Age | Match length | Substitutions |
|---|---|---|
| U13 | 3 x 25-minute periods, two 5-minute intermissions | 2 moments per period, unrestricted; intermissions do NOT count as a moment |
| U14 | 2 x 40-minute halves, 15-minute halftime | 3 moments per half, unrestricted; halftime does NOT count as a moment |
| U15 | 2 x 45-minute halves, 15-minute halftime | 3 moments per half, NO re-entry in the half; halftime does NOT count as a moment |
| U16 and up | 2 x 45-minute halves, 15-minute halftime | Unlimited over 3 moments per MATCH, plus halftime; no re-entry |
Exceptions apply under the MLS NEXT Concussion Protocol.

Note the differences: Academy Division halftime is 10 minutes, Homegrown is 15, and Homegrown U16+ uses 3 moments per match, not per half.
